# 产业园投资测算 V2：纯视觉样式调整

本版本以 `AI WORK/V1/交付文件/产业园投资测算.xlsx` 当前实际保存的内容为唯一基准。`apply_style.py` 直接读取现有文件，包括用户已经保存的参数修改；不会调用任何模型生成脚本、初始化默认参数或重算公式。

## 文件

- `产业园投资测算_V2_样式调整.xlsx`：样式新版。
- `apply_style.py`：完整纯样式补丁脚本，包含自动内容比较和原文件 SHA256 检查。
- `requirements.txt`：脚本运行依赖。
- `样式调整验证说明.md`：本次验证结果、视觉范围和限制。
- `产业园投资测算_V2_样式调整_验证结果.json`：机器可读的逐项比较结果。
- `_过程文件`：内容基准、独立比较、反例测试、参数保留测试及 Excel 原生预览。过程文件里的试稿、测试参数副本不作为正式模型使用。

## 环境与安装

支持 Python 3.10 或以上。本次实际运行环境为 Windows、Python 3.12.14、lxml 6.1.1。正式脚本仅依赖 lxml 和 Python 标准库；生成与比较都不需要安装 Excel。

在本目录打开 PowerShell 或终端，执行：

```powershell
python -m pip install -r requirements.txt
```

本次额外检查使用了 openpyxl 3.1.5（只读解析）、Pillow 12.3.0、pypdfium2 5.13.0，以及已安装的桌面 Excel 16.0。这些不属于 `apply_style.py` 的运行依赖；可选验证依赖列于 `_过程文件/requirements_qa.txt`。

## 生成命令

保持 V1/V2 为同级文件夹时：

```powershell
python apply_style.py
```

默认读取脚本所在文件夹的同级 `V1/交付文件/产业园投资测算.xlsx`，默认输出到脚本所在 V2 文件夹。默认路径与终端当前目录无关。

也可以显式指定任何现有原文件与输出位置：

```powershell
python apply_style.py --input "C:\项目\原模型.xlsx" --output-dir "C:\项目\样式新版"
```

先在 Excel 中保存需要保留的参数，再执行脚本。脚本读取磁盘上的已保存内容；Excel 中尚未保存的修改无法读取。如果原文件在执行期间发生变化，脚本会拒绝输出。

再次运行默认命令，会读取原文件当时保存的最新内容，重新应用本版样式。它不会从旧 V2 自动提取用户修改；要处理已修改的 V2，请用 `--input` 指向该文件。同名输出已存在时添加时间和必要的编号，采用排他方式写入，不覆盖旧文件。内容基准和验证报告也采用唯一文件名。

只做比较，不生成或修改 Excel：

```powershell
python apply_style.py --input "..\V1\交付文件\产业园投资测算.xlsx" --verify-only ".\产业园投资测算_V2_样式调整.xlsx"
```

比较通过时退出码为 0，发现差异时为 1。若原 V1 在交付以后又被用户修改，与本次 V2 的比较出现差异是正常现象；本次输入内容基准保存在 `_过程文件`。

## 样式修改与保留方式

视觉常量集中在脚本顶部的 `THEME`、`TAB_COLORS`。字号、角色样式集中在 `StyleRegistry.make`；内容角色判断在 `classify`。脚本中没有投资模型的默认参数、收入成本或现金流公式。

本版应用深灰主标题、蓝色模块标题、浅蓝表头、浅灰明细与合计、浅蓝关键结果、黄底蓝字输入。普通公式使用中性色。达标、未达标和不适用继续由原来的条件格式判断；本次连条件格式差异样式也原样保留。

处理方式是直接修改现有 xlsx 的 OOXML 包：给原单元格派生并引用新字体、填充、边框和对齐定义，修改允许的显示缩放及标签颜色，并按文字需要调整现有行高。本次列宽、看板行高及看板列宽均未变化，保持图表的实际布局。所有原样式定义仍保留；数字格式、保护、缩进、旋转、斜体、下划线、字体主题方案等非白名单属性均继承原值。

公式及缓存所在单元格的 XML 内容完全保留，仅替换样式索引。图表、绘图锚点、关系、共享文字、命名范围、计算链、计算设置、批注、表格和文档属性等其余包内成员原样复制。公式不会被改写或求值。

参考 Excel 和参考 Python 在制作时只用于观察样式及阅读定义。运行本脚本无需两份参考文件。参考 Python 从未运行，其模型数据、公式、校验规则和绿色公式字体规则均未进入新版。

## 自动验证

每次运行先记录输入 SHA256、每个包内成员 SHA256，以及全部非空单元格的原始内容、公式、缓存和类型，再生成候选文件。候选文件和保存后的文件都要通过比较：

1. 所有单元格地址、类型、值、文字、公式和缓存，仅剔除样式索引后逐字节比较。
2. 所有单元格有效数字格式与其他非白名单样式属性比较。
3. 工作表整体 XML 除明确允许的视觉属性外完整比较，覆盖隐藏、冻结、合并、数据验证、条件格式判断逻辑、保护、打印、分页等设置。
4. 图表及绘图 XML、全部关系、工作簿设置及其他包内成员逐字节比较。
5. 原文件 SHA256 前后相同。

发现非样式差异时，脚本记录失败报告并拒绝交付候选文件。脚本不会尝试修正原模型。

## 显示及验证限制

原模型的 `利润与现金流` 第 53、133 行有极大 DSCR 辅助筛选值，原版已有 48 处显示为 `####`。本版保留其值与数字格式；金额与关键指标未发现新增 `####`。具体地址及检查记录见验证说明和过程文件。

显式字体设置采用微软雅黑；原来的主题字体、字体方案及条件格式差异样式全部保留，因此 Excel 检测仍有部分单元格使用宋体。为遵守白名单，不改工作簿主题或字体方案。当前环境中两种字体均清晰可读。

本次在手动计算模式下，对临时副本进行 Excel 原生 PDF 渲染和显示检查，临时副本不保存。正式输出未重算；原有自动计算设置保持不变。若原文件缓存尚未反映最新输入，本版会如实保留该缓存，不能把缓存保留当作财务计算正确性的新验证。打开新版或修改参数时，Excel 仍按原有计算设置工作。

视觉复核覆盖全部 10 张表的主要区域、压力区域和三张图表，并对 Excel 中全部 9,366 个非空内容单元格扫描 `####` 和公式错误显示。没有逐页审查原工作簿全部打印分页，也没有在所有 Excel/WPS 版本和不同字体环境中检查布局。原打印设置及原内容布局保持不变。
