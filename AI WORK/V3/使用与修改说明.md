# 产业园投资测算 V3

本版以V2文件实际保存的参数为来源，保留原示意数值及判断阈值。V1生成代码仅用于追溯财务关系，没有运行旧生成器重置参数，也没有覆盖V2。

## 使用

1. 用桌面Microsoft Excel打开正式工作簿。黄色蓝字单元格可填写，公式区已做防误改保护，未设置密码。
2. 在“核心参数输入”设置经营模式、建设及租售起点、投资、融资和期末口径。原年度建设、销售计划继续保留。
3. 新增参数集中在95行以后，全部为示意、待核对。尤其要核对收款节奏、出租率定义、土地摊销、亏损结转、税款支付、费用包含范围和期末回收。核对完成后再使用“新增假设已完成项目核对”开关。
4. 默认按年度计划和四季权重分解；“季度计划”的黄色覆盖区可以按已知安排逐季填写。空白表示采用默认，零表示该季确实不发生。工程形成、现金付款和贷款提款分别排布。
5. 先看“决策看板”，再检查“指标与情景”“年度汇总”和具体季度缺口；“模型校验”用于独立勾稽。校验通过不等于项目值得投资。
6. 修改输入后，Excel公式和原生双变量数据表可以重算。精确边界是同一模型重复求解的快照，修改参数会提示需要刷新。

## 刷新精确边界

先保存并关闭工作簿，然后在本目录的PowerShell执行：

```powershell
.\刷新_V3.ps1
```

需要电脑安装桌面Microsoft Excel。脚本启动独立隐藏实例，反复计算同一个工作簿，恢复临时测试参数，记录边界、输入签名及时间，重建并重算原生敏感性数据表，检查公式错误后保存。

请保留本目录中的`_过程文件/manifest.json`，刷新工具用它定位可编辑区域和原生数据表。其余过程文件为构建、验算和视觉检查记录。工作簿本身没有宏、外部工作簿链接或网络数据源。

## 相比V2的主要变化

| 方面 | V3处理 |
|---|---|
| 时间轴 | 底层第0季及最多120个正季度，稳定期和结果统一汇总成年；收益指标按季度时间计算并转换成年化 |
| 经营模式 | 租售结合、纯出售、纯持有；不再强制销售比例介于0与100%之间；纯出售不承担持有运营和周转资金 |
| 工程与付款 | 工程形成、现金支付和提款分开；付款、提款滞后可以暴露季度垫资需求 |
| 销售 | 签约、交付、收入及收款分离；首款、尾款分季；未收款保留应收，不自动变现 |
| 出租 | 首3年与稳定出租率改为各出租年末目标；按季形成平均出租面积，免租跨季跟踪新增租户队列 |
| 运营成本 | 固定和常年维护按基准持有面积缩放；重大更新单列金额及年份；默认仍费用化，使用时需核对 |
| 税费 | 保留原综合税费模式，另提供分离增值税的财务参数；税费计提与现金支付分开，进项留抵滚动，不自动退款 |
| 所得税 | 按年度利润计算；项目与融资口径分别结转亏损，按年份先进先用并检验到期；持有和出售分别计算末年税额 |
| 土地与折旧 | 建筑折旧和持有土地摊销分开；融资成本仅进入融资口径的销售成本和持有建筑成本 |
| 融资 | 固定额度、季度提款和计息、合同计划还本；计划余额为零不表述为实际已偿还；无自动增贷或再融资填口 |
| 资本金 | 保留理论完整出资、留存和额度内路径，明确缺口路径无法视为已执行 |
| 期末 | 持续持有与期末出售并列；周转资金分路径设置回收比例；已计提未支付税款在期末作为负债结算扣除 |
| 结果 | 增加峰值资金及发生期、经营DSCR与留存现金、应收和账面净值、持有及退出回报 |
| 校验 | 分别检验周转回收和处置总额、末期金额与其他期间为零；增加存量/流量、应收、资本成本和模式勾稽 |
| 敏感性 | 原生双变量数据表；土地、售价、租金、出租率、成本和延期边界由同一模型反复求解，带过期提示 |

## 重要财务口径

- 原示意数值保留，不意味着V3结果必须与V2一致。季度时点、回款延迟、年末出租目标、土地摊销、亏损结转和期末周转处理都会改变结果。
- 新增税率、进项比例为零，仅是未核对的示意值，不代表实际适用税率。默认综合模式继续使用V2的销售及运营综合税费率。新增土地摊销50年、亏损结转5年也是模型测试假设，不是实际规则判断。
- 其他条件固定的NPV边界，与同时满足收益、回收期、偿债、资本金额度及资金缺口的边界分开。未找到可行值、仍满足搜索上限和不适用会明确列出，不用零冒充。
- 精确边界先扫描寻找可行区间，再二分临界值；不是多变量全局最优。压力情景设置为必须通过时，综合边界也检验压力情景。
- 整体开发延期表示土地先投入、后续开工及租售整体后移，原建设跨度不变；施工过程延长、合同付款不随进度变化等情况，需直接调整季度形成和付款安排，不能只用整体延期替代。
- “关键月份核对”可以选择基准或压力情景的任一季度，调整经营收款、付款、提款、出资和本息支付的月内权重。它检验所选季度，不代表全期月度最大缺口；利息仍沿用季度已测金额，精确边界按季度约束求解。
- 本版仍为同质业态、一次开发模型，未建立多业态差异价格成本、多分期、多笔债务、租户更替及预售专项资金安排。
- 本版仅改善财务测算，不开展合法性或政策合规审查，不评判示意参数是否符合市场，不直接作出真实项目拿地结论。

## 文件和复现

正式工作簿与本说明、刷新工具放在V3根目录。构建脚本、源参数提取、原生重算、独立数值复算、边界测试和视觉检查在`_过程文件`。构建脚本读取指定V2的实际保存内容；不应通过旧V1生成器覆盖已修改的参数。

需要复现构建时，先检查并调整`_过程文件/extract_source.py`的来源，再依次运行参数提取、`build_v3.mjs`、`build_v3.mjs --patch`（增加本地输入保护条件和关键月份核对）、`format_repairs.py`、`build_v3.mjs --fix`，对候选执行原生重算、验算及最终刷新。运行环境位置来自当前桌面内置依赖，迁移电脑时需配置对应Node依赖及Python只读验算环境。

日常修改V3后只运行“刷新_V3.ps1”。构建脚本用于重新基于V2生成，不会自动保留既有V3中手改的参数；需要保留时应先另存并核对输入来源。
