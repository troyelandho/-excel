# 产业园投资测算：运行与使用

此包用于个人学习和模拟。默认项目、价格、成本、贷款及判断阈值均为虚构模拟值；未为使结论通过而调整默认假设。交付工作簿已使用 Microsoft Excel 实际重算，并恢复默认输入。

## 文件

| 文件 | 用途 |
|---|---|
| 产业园投资测算.xlsx | 10张工作表，完整公式、基准与压力情景、3张动态范围图表和决策看板 |
| generate_excel.py | 全部工作簿内容、公式、格式、图表及校验的生成器 |
| validate_model.py | 独立数值模型、Excel参数修改测试及结构/依赖检查；不向工作簿填入计算缓存 |
| requirements.txt | 实际使用版本的公开依赖 |
| 验证说明.md | 默认结果、判断状态、各项实际验证范围及情景结果 |

## 环境及安装

已验证：Windows、Python 3.12.14、Microsoft Excel 16.0。生成器自身只依赖 XlsxWriter；openpyxl 和 numpy 用于验证。建议 Python 3.12 的64位版本，以安装本清单中的已验证依赖。

在本文件夹打开终端：

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python generate_excel.py
```

若终端限制虚拟环境激活，可直接运行 `.venv\Scripts\python.exe -m pip install -r requirements.txt`，随后使用同一解释器运行代码。

输出默认在代码所在文件夹。可指定其他位置：

```powershell
python generate_excel.py --output-dir .\新示例
```

同名工作簿已存在时，自动在新文件名中加入时间标识，**不会覆盖旧文件**。重新运行生成新的默认示例，**不会读取或保留旧Excel中手改的参数**。

## 公式重算

Python生成器写入普通Excel公式，不实现Excel计算引擎。新生成但未重算的文件可能显示初始缓存0；这不代表模型结果。文件设置为打开时自动计算，使用支持公式的软件打开后应等待重算完成。日常Excel中将“公式→计算选项”设为自动，可用 Ctrl+Alt+F9 执行完整重算。

在已安装桌面版 Microsoft Excel 的Windows电脑上，可使用：

```powershell
python generate_excel.py --recalculate
```

该命令通过系统 Windows PowerShell 和COM启动一个独立隐藏Excel实例，重算并保存新示例，然后关闭该实例。不会接管已打开的用户工作簿。无需额外Python COM库。Excel须是已安装并完成初始配置的桌面版本；可通过已有Microsoft 365/Office安装程序安装。Excel无法启动时命令会明确报错，但已生成的完整公式文件会保留。

没有Excel也可以生成全部表格、公式、样式、数据验证、条件格式及图表定义，并运行独立Python数值模型；无法仅靠此生成器执行Excel公式或证明实时联动。也可安装LibreOffice Calc打开重算（从其官方网站下载安装），但**本次未验证LibreOffice、WPS、网页版Excel或其他系统的兼容性**。

## 输入与调整

日常只修改工作簿“核心参数输入”的浅黄色蓝字单元格。全部金额输入为万元，面积为平方米，单价为元/平方米，租金为元/平方米/月。百分比字段按Excel百分比输入；出租率压力以百分点输入，10表示下降10个百分点。

建设及销售的31年计划也在该表。调整建设年限或销售开始年时，需要同步修改对应年度比例。建设计划累计100%；销售计划累计≤100%，超出测算期或提前销售会触发校验。出租率由前三个出租年度及稳定出租率驱动，必须不下降，避免在不模拟租户更替的简化前提下重复给免租。

期限N可调至30年：IRR、NPV、回收期、期末回收及图表范围都读取N；必须覆盖贷款到期。看板显示两情景的指标和30项校验。压力默认供观察；开启“要求压力情景也通过”后，两情景均需通过。

代码默认参数集中于 `PARAMETERS` / `DEFAULTS`，建设和销售默认序列集中于 `DEFAULT_BUILD_PLAN` / `DEFAULT_SALE_PLAN`；工作表名、年度上限、行映射及样式色值集中在文件顶部。这些默认值只负责初始化新示例。

## 主要简化口径

1. 第0年支付土地；第1—K年建设，销售与出租在建成后开始。现金流以第0年初始及后续年末表示；年度贷款利息采用期初余额加半年度提款、减半年度还本的近似。
2. 地上经营面积拆为销售和持有；销售部分始终不出租，地下及非经营空间不单独产生收入。全部共同开发成本按销售/持有经营面积比例分摊。
3. 非土地建设成本包含建安、配套、前期、建设管理及预备费，范围不重叠；压力成本增幅作用于全部非土地成本及对应预备费，土地和贷款不变。
4. 销售当年回款，收入及税费为统一简化含税实收口径。租金扣新增面积一次免租和收缴影响；不模拟租户更替、复杂增值税、税种拆分或亏损结转。
5. 固定成本自建成后首年发生，空置也支付；维护更新费用化、作为现金支出并当期税前扣除，不再资本化折旧。
6. 销售成本按年度销售比例结转，持有建筑直线折旧，土地不折旧。建设期间存货/在建成本按累计实际支付展示。建设成本现金支出、成本结转及折旧分开，避免重复扣现金。
7. 一笔贷款按建设比例提款，到期年＝首次提款年＋贷款期限－1；建设后至到期前等额本金。建设期利息资本金承担，不滚入贷款。无额外提前还款。
8. 项目现金流及无融资所得税不含任何贷款、资本金和利息；总投资包含建设期利息。融资利润的销售成本及持有折旧另包含分摊资本化利息。资本金收益用完整出资计划下的实际出资时点及分配测算。
9. 反向留存未来计划净支出所需现金，剩余才分配；按当年需要投入资本金。另计算额度内现金路径，未落实支出缺口单列并滚动，不能作为真实资金或分配；历史缺口导致未通过。发生缺口的执行计划不具备真实可行性，后续收入仅为定位缺口的条件测算。
10. 默认不变现期末物业或未售存货。开启处置后，只使用输入的持有物业处置价，扣综合交易费用，并将净额减账面值纳入年度所得税损益。周转资金第N年全额收回。
11. 静态/动态回收期均取项目现金流，含建设期并跨年插值；未回收不达标。IRR无解显示无法计算，多次变号另提示。现金流符号检查忽略≤0.000001万元尾差，金额判断容差0.01万元。
12. 稳定观察取第4个出租年度；NOI扣运营、经营税及维护，不含融资和所得税。保本出租率按稳定全年无新增免租计算。不把NOI收益率等同于IRR。

## 重跑验证（可选，Windows桌面Excel）

使用仅供验证的示例文件；测试会在临时副本中改变参数并恢复代码默认值，验证后另生成一个不覆盖原文件的已重算示例。

```powershell
python validate_model.py prepare --book .\产业园投资测算.xlsx --work-dir .\验证临时文件
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\验证临时文件\run_excel_tests.ps1 -WorkDir "$PWD\验证临时文件"
python validate_model.py check --book .\产业园投资测算.xlsx --work-dir .\验证临时文件
```

PowerShell脚本和清单由公开源代码即时生成，不依赖隐藏文件。结果在指定临时文件夹中的 `actual_results.json`、`validation_summary.json` 和 `visual_qa`。所有19组测试的两个情景均与独立Python数值计算逐年核对。

没有Excel时可以查看独立计算，但这不能替代Excel公式及联动验证：

```powershell
python validate_model.py oracle
```
